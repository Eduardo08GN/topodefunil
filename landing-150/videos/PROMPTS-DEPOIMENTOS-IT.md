## ⛔ AS TRÊS CORREÇÕES DE ITALIANO

| | |
|---|---|
| **`euro` é invariável** | `dieci euro`, nunca `dieci euri`. `euri` é erro de gramática |
| **tamanho de roupa é NÚMERO** | `dalla taglia cinquantotto alla quarantasei`, nunca `dalla XXL alla M` |
| **a bebida da noite é `tisana`** | `tè` é chá com cafeína, de manhã. À noite se toma `tisana` ou `camomilla` |
